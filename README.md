# NewFuckMarketAds

## 说明 / Desc

NewFuckMarketAds 是一款面向小米应用商店的广告移除 Xposed 模块，通过挂钩应用商店核心逻辑，实现各类广告与冗余功能的屏蔽/移除。

## 功能 / Func

- 移除开屏广告
- 禁止切换前台展示广告/推荐
- 隐藏信息流广告低栏（视频/应用推荐、热词）
- 移除搜索建议/搜索页/搜索结果的软件推荐
- 移除应用升级页与下载页的软件推荐
- 移除应用详情页的广告、评论与推荐
- 隐藏应用安全检测视图
- 精简底部标签栏（仅保留 首页 / 我的）
- 细节修正（显示非正版 APP、被隐藏的更新等）
- 禁用系统更新（Updater）的 OTA 验证

## 程序主页与各功能开关 / UI & Toggles

模块自带一个 **Launcher 主页（MainActivity）**，打开后可看到：

- 框架激活状态（是否已被 LSPosed 等框架加载、是否支持远程偏好）；
- **总开关**：关闭后所有功能均不生效；
- 上述每一项功能的独立开关，可单独启用/停用。

开关状态通过 libxposed 的 **远程偏好（Remote Preferences）** 在模块 App 进程与 hooked 进程之间同步：

- 写入：主页通过 `XposedService.getRemotePreferences("settings")` 写入；
- 读取：hook 进程内通过 `XposedModule.getRemotePreferences("settings")` 读取（见 `Settings.kt`）。

**开关何时生效（重要）：** 每个功能开关都在对应 hook 的**每次调用时实时读取**，因此：

- 在模块主页拨动任意开关后，**一般无需手动重启**目标应用（远程偏好会在模块侧写入后实时同步，下一次相关界面加载即生效）；
- 若个别 ROM / 框架版本对远程偏好做了快照缓存，重启一次目标应用（小米应用商店 / 系统更新）即可确保生效。
- 总开关为全局兜底：关闭后所有 hook 在加载期即跳过。

> 早期版本把子开关放在“安装期”判断，导致拨动子开关必须重启应用才生效（表现即“子开关无效”）。现已改为运行时实时受控。
